# NEXIS I.D.E.A Labs

Two presentations for school partnerships: the Entrepreneurship Lab for Classes 6–12 and the AI Lab for Classes 8–12.

- `index.html`: full 23-slide version, including Programme pricing.
- `no-commercials.html`: 22-slide version without Programme pricing or the pricing reference in next steps.

Open either file in a browser. Navigate with the arrow keys or the on-screen controls, and use the full-screen button when presenting.

Fonts, photographs and logos are embedded in the HTML, so the deck can also be used offline.

## Vercel deployment

- Production: https://nexis-idea-labs.vercel.app
- Project: `nexis-idea-labs` in the `appycodes-demo` team.
- Git integration: pushes to `main` in this repository automatically deploy to production.
- Framework: static HTML; no build command or environment variables required.
- Deployment Protection is enabled; Vercel authentication may be required to view the production URL.
