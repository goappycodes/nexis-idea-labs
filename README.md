# NEXIS I.D.E.A Labs

A 19-slide presentation for school partnerships: the Entrepreneurship Lab for Classes 6–12 and the AI Lab for Classes 8–12.

Open `index.html` in a browser. Navigate with the arrow keys or the on-screen controls, and use the full-screen button when presenting.

Fonts, photographs and logos are embedded in the HTML, so the deck can also be used offline.
